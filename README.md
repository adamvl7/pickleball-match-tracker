# Pickleball Match Tracker

A full-stack web application that allows pickleball players to log matches and track performance over time through win/loss statistics and match history.

## ✨ Features
- Log match details (date, opponent, scores, outcome)
- Automatic win/loss tracking
- Match history with notes
- Delete and manage match entries
- Clean, responsive UI
